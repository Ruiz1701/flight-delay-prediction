# ✈️ Flight Delay Prediction

## Overview

This project uses machine learning to predict whether a flight will be delayed based on historical flight and weather data. The goal is to help airlines and travelers better anticipate delays and improve planning.

---

## Objectives

- Clean and preprocess raw flight data
- Explore patterns and relationships within the dataset
- Train machine learning models to predict flight delays
- Evaluate model performance using classification metrics

---

## Dataset

- Historical airline flight data
- Weather information
- Flight schedule information

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

---

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis

5. Model Evaluation

## Results

- Identified important factors contributing to flight delays
